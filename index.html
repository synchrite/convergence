Charge! Convergence

A game about servicing a CRT monitor, written for DOS on a 486 and running here in a DOS emulator.

Click the screen first so the keys go to the game. It takes a few seconds to start.

Up, Down, Enter, EscMenus
TabNext group of controls on the bench
Up, DownPick a control
Left, RightTurn it (Page Up, Page Down for bigger steps)
F1 to F5Test pattern
D, H, MDegauss, hint, music on or off
EnterShip the set to the customer

The same program runs on a real PC: download CONVERGE.EXE (486, SVGA with VESA, AdLib or Sound Blaster). Never open a real monitor unless you are trained: it holds lethal voltages.
